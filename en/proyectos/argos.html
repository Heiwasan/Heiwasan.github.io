ARGOS

About the project

This is a web-based document management platform. It organizes each client's files in folders (cabinets), stores the versions of each document, handles approvals and adds text recognition (OCR) and AI summaries.

Web screens

1 / 5

My contribution

  • Requirements gathering and definition of how documents are uploaded, edited, approved and restored.
  • Design of the dashboard with document and status reports.
  • System analysis: users, roles, groups, products and document types.
  • Visual design of the AI and OCR features: folder summaries and data extraction when a document is uploaded.
  • Manual build of the design.
